# ERP Management System

A multi-tenant enterprise ERP SaaS platform designed for wholesale,
distribution and multi-branch retail organizations.

## Architecture

- Domain-oriented modular monolith
- NestJS and TypeScript backend
- React and TypeScript frontend
- PostgreSQL
- Prisma
- Redis and BullMQ
- S3-compatible object storage
- Transactional outbox
- Double-entry accounting
- Movement-based inventory
